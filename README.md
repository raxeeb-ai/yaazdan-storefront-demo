# YAAZDAN — Animated Storefront Demo

A responsive, motion-enhanced ecommerce storefront concept for YAAZDAN, featuring an animated Y/R/M monogram concept, category browsing, product cards and a demo shopping bag.

Named in loving memory of Rehan Mohammad Yaazdan (02 August 2025 — 11 August 2025), beloved son of Razib and Mimi.

## Preview

Enable GitHub Pages in **Settings → Pages → Deploy from a branch → main / (root)**.

## Note

This repository contains a standalone web demo. It uses a CSS-based animated monogram placeholder, not the original uploaded gold logo artwork. Sample product imagery loads from Unsplash. No real payment, checkout, or backend is connected.
